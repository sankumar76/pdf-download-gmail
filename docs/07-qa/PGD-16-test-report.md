## Exploratory Testing

- **Option-like values (EC-4).** `--start -1` is taken as the value (argparse sees a negative number): the format line, exit 2. `--start -x`, `--start --end 2026-01-31` and `--start --tz UTC` are argparse's `expected one argument` (usage, exit 2, no value echoed), both modes. `--start=`, `--end=`, `--tz=` and `--tz ""` give the format line (`--start:`/`--end:`) or the zone line, exit 2. `--start=2026-01-01=x` gives the format line. All three `=` forms together work. Repeated flags: the last value wins (`--start x --start 2026-01-01` runs; `--start 2026-01-01 --start x` is rejected; the repeated `--tz` last value wins). `--` and extra positional text give argparse's `unrecognized arguments: -- ...` (exit 2).
