## Exploratory Testing

**Charter:** break the three test-support seams that every later story will build on (the egress guard, the fake mailbox with its fault scripting, and the bootstrap hook), and confirm that the AC-5 and AC-6 gates fail when they should. **Time-box:** one 90-minute session. **Areas:** socket guard bypass routes; fake mailbox fault sequencing, paging, epoch interpretation and query handling; hook environment-variable partitions and malformed files; allow-list and import-boundary mutations; wheel contents and the hook from a wheel; per-file independence and repeat-run determinism.

**Observations**
- The risk areas flagged at G6 (QUA-01 relative imports, QUA-09/QUA-13 guard coverage, QUA-08/STD-09 hook errors, QUA-02/04 fault and query validation) all behaved correctly on the final head.
- Defects found: DEF-001 (raw `RecursionError`, `ValueError` and `KeyError` from hand-crafted hook and fake input) and DEF-002 (`sendmsg` unguarded on Unix legs). Both Sev-4.
- A mailbox file saved with a UTF-8 BOM (Windows PowerShell's `-Encoding utf8`) is rejected as unreadable. This is safe and the message is clear, so it is a usability note for the later stories that author mailbox files, not a defect.
- A malformed `base64` attachment string such as `!!!` is accepted and decodes to empty bytes (Python's lenient decoder). Harmless for a fake.
- The 38 GitHub review threads all show as unresolved in the PR, because `REVIEW_IDENTITY = single-token` records the disposition in a reply (Fixed, Deferred, Accepted) rather than by resolving the thread. I read the last reply on every thread and all dispositions are in order. Housekeeping only.
